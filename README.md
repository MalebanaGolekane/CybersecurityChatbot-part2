
# CybersecurityChatbot-part2 - POE PROG6221

## Project Description
A C# WPF Cybersecurity Awareness Chatbot that educates users about online safety, phishing, passwords, scams, and safe browsing practices.

## Features
- Interactive cybersecurity chatbot (Chatbot.cs)
- WPF User Interface
- ASCII Art Logo
- Educational responses on cybersecurity

## How to Run
1. Clone the repository
2. Open CybersecurityChatbot-Part2.sln in Visual Studio 2022
3. Build and Run (F5)
